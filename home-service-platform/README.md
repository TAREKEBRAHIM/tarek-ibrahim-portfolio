# خِدمة | إدارة خدمات الصيانة المنزلية

لوحة عمليات عربية متجاوبة لإدارة طلبات الصيانة المنزلية، متابعة الفنيين، وتحديث حالة التنفيذ.

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادم معاينة البورتفوليو من المجلد الرئيسي باستخدام `node serve.cjs` ثم افتح `http://localhost:8080/home-service-platform/index.html`.

## الوظائف

- لوحة ملخص الطلبات اليومية والإيرادات وحركة الأسبوع.
- قائمة طلبات قابلة للبحث والتصفية حسب الحالة.
- إضافة طلب جديد وتعيين الفني وموعد الزيارة والسعر التقديري.
- تحديث حالة الطلب من جديد إلى قيد التنفيذ ثم مكتمل.
- عرض بيانات الفنيين وحالة التوفر والطلبات المسندة.
- حفظ الطلبات في `localStorage` لتظل متاحة في الزيارة التالية.

البيانات المعروضة تجريبية ومحلية داخل المتصفح؛ لا يوجد خادم أو تسجيل دخول في هذه النسخة.
